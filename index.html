KG_RIDE 사용법

자전거 주행을 기록하는 앱입니다. 속도·거리·경로·고도를 GPS로 측정하고 음성으로 안내합니다.

접속

설치 없이 웹 주소로 엽니다. 처음 START를 누르면 위치 권한 허용을 묻는데, 반드시 허용해야 측정됩니다. 자주 쓰려면 브라우저의 "홈 화면에 추가"를 해두면 편합니다.

주요 기능

현재 속도·이동 거리(위쪽 큰 박스), 평균·최고 속도·경과 시간·현재 고도(4개 박스), 현재 위치 주소를 보여줍니다. 라이딩 경로는 지도에 실시간으로 그려지고, 현재 위치는 연두색 점으로 표시됩니다.

음성·화면 알림 (2회 안내)

시작 시 "라이딩을 시작합니다", 2km마다 "○킬로미터 지났습니다", 지역이 바뀌면 "○○에 진입합니다", 완료 시 "라이딩을 마칩니다"를 알립니다. 설정 탭에서 켜고 끌 수 있습니다.

버튼

START 측정 시작 / STOP 일시정지(RESUME으로 이어감) / 완료 끝내고 저장. 저장하면 주행 기록 탭에 날짜별로 쌓입니다.

주의사항

• 야외 트인 곳에서 쓰세요. 실내·차 안은 GPS가 약합니다("GPS 약함" 표시).
• 자전거 전용입니다. 40km/h 초과는 오류로 제외돼 자동차로는 측정이 안 됩니다.
• 라이딩 중 화면을 켜둔 채로 두세요(자동 꺼짐 방지 있음).
• 속도·거리는 인터넷 없이 되지만, 지도와 주소는 인터넷이 필요합니다.
• 기록은 이 폰의 브라우저에만 저장됩니다. 다른 폰·브라우저와 따로이고, 브라우저 데이터를 지우면 사라집니다.
• 고도는 GPS 기반이라 대략적인 참고용입니다.

각 버튼을 눌러 켜고 끌 수 있습니다. 지도 버튼은 북쪽 고정 ↔ 진행 방향 위를 전환합니다.
